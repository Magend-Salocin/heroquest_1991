Paquet de données

Ce site ne contient que le moteur du jeu. Les fichiers du jeu de 1991, le code traduit et les sons viennent d'un paquet fabriqué sur le PC depuis votre copie du jeu (node outils/paquet.mjs).

Choisissez le fichier heroquest-donnees.bin : il est gardé sur cet appareil, et le jeu marche ensuite hors ligne.
